# Pass-2 evidence (sanitized)

Generated by `../diagnostics/export_evidence.py` from the external study root
`E:\CSC2108Local\reasoning-effectiveness-pass2`. It holds **counts, frontier-written text and hashes only**.

Excluded: candidate programs, E evidence packets (they embed the failed program), hidden tests, trajectories
and Codex event logs. Those stay outside Git in the study root.

| File | Content |
| --- | --- |
| `selection-pass2.json` | Outcome-blind validation selection: rule, pool sizes, excluded output types |
| `FREEZE-val.json` | Freeze written before any validation run: code commit, prompt, template and artifact hashes, 25-attempt plan |
| `api-ledger.json` | Every paid request of this pass (8): purpose, token usage, cost, latency. Never contains credentials. |
| `guidance/` | Contract and plan artifacts: `dev-v3-codex`, `dev-v1-codex`, `val-codex` (frozen) and `val-api` |
| `diagnoses.json` | Every E diagnosis: provider, candidate/report/statement hashes, verdict, diagnosis text, usage, outcome record. Entries with provider `fixed` are the synthetic integration-test fixture. |
| `analysis-contract-checks.json` | Endres-style correctness and mutant-kill counts per contract artifact |
| `analysis-kcheck-programs.json` | Verified contract-v3 K-checks satisfied by each final program (counts) |
| `pass2-tables.md`, `pass2-rows.json` | Generated per-task tables and per-run metrics for pass-2 batches and the pass-1 references |
| `plans/` | Batch plans as executed |

Guidance artifacts record the local Codex executable path in their isolation block, as pass-1 evidence does.
The files are unaltered so that their hashes match `FREEZE-val.json`.
