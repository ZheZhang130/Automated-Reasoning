## Audit findings

The two release blockers are Codex isolation and the paid ledger’s hard ceiling. The saved traces support pre-trigger reproducibility on the sampled runs, and Phase 1A shows a detection–repair gap. ### Blocker

1. **Codex replay lacks a filesystem read boundary.** The wrapper uses an empty directory under the study root, `--ephemeral`, `--ignore-user-config`, `--ignore-rules`, `--strict-config`, read-only mode, and disabled shell, web search, and other tools. The environment filter leaves `CODEX_HOME`, profile and proxy variables, and credential names outside its denylist. User config suppression still permits authentication through `CODEX_HOME`. The wrapper neither isolates global `AGENTS.md` discovery nor enforces a filesystem or network allowlist for the CLI process. All 116 saved event streams I checked showed no tool events, but the post-run audit cannot establish what startup loaded. **Fix:** run with a clean instruction/config environment, OS-enforced denial of repo and study reads, and inference-only egress. Record the effective policy and CLI version.
