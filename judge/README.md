# Judge

The judge black box specified in [timeline/judge_1114.md](../timeline/judge_1114.md). It runs a stdin/stdout Python submission against one task's tests and returns a result JSON.

Requirements:
- Python 3.10+ (standard library only)
- A running Docker engine (Docker Desktop, OrbStack or Colima)
- Network access the first time, to download the dataset

## Setup (one command)

```sh
cd judge
./setup.sh            # tasks/, image, judge-public, selftest
./setup.sh --hidden   # evaluation owner: also hidden/ and judge-hidden
```

`setup.sh` performs four steps:
1. `build_data.py` downloads the LiveCodeBench shard at the pinned revision and checks its sha256.
2. It rebuilds exactly the tasks in `manifests/` and fails if any test hash differs from the manifest.
3. It builds the image. The base image is pinned by digest.
4. It starts the container(s) and runs the selftest.

Two machines therefore end up with identical data and the same image, or the setup fails.

## Use

```sh
python3 -m judgekit run --task lcb-atcoder-abc393_a < solution.py    # debugging aid; the contract is the Python API
python3 -m judgekit run --suite hidden --task ... < solution.py
python3 -m judgekit info | selftest | down [--suite hidden]
```

```python
from judgekit import Judge
judge = Judge.public()                                # starts the container if needed
result = judge.run("lcb-atcoder-abc393_a", code)      # dict, schema in timeline/judge_1114.md
```

## Tests

```sh
python3 -m unittest discover -s tests   # uses tests/fixtures; container tests skip without Docker
```

## Layout

| Path | Contents | Git |
| --- | --- | --- |
| `setup.sh`, `build_data.py` | One-command setup and the data rebuild | yes |
| `container/judge.py` | Judge inside the container: `load`, `info`, `run`, `selftest` | yes |
| `judgekit/` | Host-side client and CLI | yes |
| `Dockerfile` | `csc2108-judge` image (python:3.12-slim pinned by digest, runner users) | yes |
| `manifests/` | Frozen task selection (pilot 8, main 60) with test hashes | yes |
| `tests/` | Unit and container tests, two built-in fixture tasks | yes |
| `tasks/`, `hidden/`, `.cache/` | Generated by `setup.sh` | no |
